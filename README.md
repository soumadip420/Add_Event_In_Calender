# My Events - Event Booking & Management Web App

A clean, responsive, and interactive frontend web application designed for booking and managing events seamlessly. Users can view available dates on an interactive calendar, search for events, and fill out a comprehensive event registration form.

## 🚀 Features

*   **Interactive Header & Navigation**: Features a top navigation bar ("My Events") for seamless access, including an integrated event search functionality.
*   **Simple Authentication**: A dedicated, lightweight login section requiring only a Name and Email to get started.
*   **Visual Calendar Display**: An interactive monthly calendar view allowing users to select their desired event dates visually.
*   **Comprehensive Booking Form**: A detailed event creation form including fields for:
    *   Event Title & Topic
    *   Event Date, Time, and Type Selection
    *   Organizer Details (Name, Email, Phone)
    *   Event Location & Additional Notes

## 🛠️ Tech Stack

This project is built entirely using standard frontend web technologies without any heavy frameworks:

*   **HTML5**: Structuring the web page layout, input forms, and semantic elements.
*   **CSS3**: Custom styling, purple-themed UI components, responsive layout alignments, and aesthetic cards.
*   **JavaScript (ES6+)**: Handles dynamic UI rendering, form handling actions, calendar interactions, and client-side event filtering.

## 📂 Project Structure

## 💻 Getting Started

To view and run this project locally on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com
   ```
2. **Navigate into the project directory:**
   ```bash
   cd YOUR_REPOSITORY_NAME
   ```
3. **Open the application:**
   Simply double-click the `index.html` file to open it in your preferred web browser, or use a development server extension like *Live Server* in VS Code.
